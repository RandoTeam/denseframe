# Support

DenseFrame is early alpha and is not suitable for financial, medical, safety-critical, forensic, or regulated use.

Use GitHub Issues for bugs, feature requests, and capture-quality reports.

Useful diagnostics include:

- device model and Android version;
- app version or commit;
- capture mode;
- tracking state and depth confidence symptoms;
- lighting, object or room type, and reflective or transparent surfaces;
- reproduction steps;
- logs or DFR snippets only when safe to share.

Do not share private raw scans, indoor spaces, credentials, signing material, or diagnostics that contain sensitive information.
