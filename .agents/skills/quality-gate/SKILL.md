---
name: quality-gate
description: Trigger before completing any DenseFrame task to verify tests, checks, documentation, and risk summary.
---

Run the narrowest checks that prove the change.
Confirm docs and ADRs are updated when behavior, architecture, storage, capture, reconstruction, or UX changes.
Summarize validation performed and any checks not run.
Report remaining risks clearly.
Do not claim tests passed unless they actually ran.
